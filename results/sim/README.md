Simulation results (`lb sim`): RTL-only, so there is no per-target split -- a single `sim.json` holds per-benchmark results from the one sim flow's two nodes: `compile` (build/elaborate the sim model) and `run` (execute the self-checking testbench). Metrics are captured per node -- `compiletime` from `compile`, and `status` (pass/fail), `simtime`, and `cycles` from `run` (SIM_METRICS). Published from a git clone with `lb sim --publish`.
