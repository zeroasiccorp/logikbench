Simulation results (`lb sim`): RTL-only, so there is no per-target split -- a single `sim.json` holds per-benchmark results from the one sim flow's two nodes: `compile` (build/elaborate the sim model) and `simulate` (execute the self-checking testbench). Metrics are captured per node -- SC's `tasktime` at both `compile` and `simulate`, plus `status` (pass/fail) scraped from the `simulate` log (SIM_METRICS). Published from a git clone with `lb sim --publish`.
