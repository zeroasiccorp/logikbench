# RISC-V Rocket Core (generated from Chisel and chipyard)

- Single-core Rocket + 16KB 4-way L1D + 16KB 4-way L1I + 128KB 2-way L2 cache
- NOTE: we have chosen not to make the generation scripts available as this would open up a pandoras box of nested chisel/chipyard/zeroasic dependencies for version that are now deprecated.
